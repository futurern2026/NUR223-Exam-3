# NUR 223 Exam 3 Study Center

A static GitHub Pages site containing the Day 1 and Day 2 NUR 223 Exam 3 study tools.

## Publish with GitHub Pages
1. Create a new GitHub repository.
2. Upload everything in this package to the repository root.
3. In **Settings → Pages**, choose **Deploy from a branch**.
4. Select the **main** branch and **/(root)** folder, then save.
5. GitHub will provide the public Pages address after deployment.

Open `index.html` locally to preview the site before publishing.
